# TPO - Fundamentos de Informática

Repo interno para organizar el desarrollo del TPO de Introducción a la Algoritmia.

## Objetivo

Desarrollar un sistema en Python basado en el escenario asignado, usando únicamente los temas vistos en clase.

## Requisitos principales

El sistema tiene que incluir:

- Login con usuario y contraseña hardcodeados
- Menú navegable con submenús
- ABM / CRUD completo
- Validaciones numéricas
- Funciones
- Listas paralelas
- Matrices para informes
- Búsquedas secuencial y binaria
- Ordenamientos:
  - selección
  - inserción
  - burbujeo
- Uso de `random.randint`

## Restricciones

No usar:

- librerías externas
- estructuras no vistas en clase
- métodos no explicados en la materia

La idea es que todo el grupo pueda explicar el código en la defensa oral.

## Datos

- Trabajar con 3 conjuntos de datos relacionados
- Mínimo 10 registros hardcodeados por conjunto
- Mantener consistencia entre códigos y relaciones

## Entrega

Se entrega:

- `.py` principal
- informe PDF
- `.zip` final
